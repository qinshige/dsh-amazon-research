# KPI 阈值、十维体检与一票否决

## 1. 十维阈值（与 host/selection/kpis.js 一致）

| 维度 | 达标 | 警戒 | 不达标 |
| --- | --- | --- | --- |
| 市场容量（Top100 月销） | 10 万–30 万 | 其余 | < 1 万 |
| 品牌集中度 | < 50% | 50%–70% | > 70%（否决） |
| 类目前十评价数 | < 1000 | 1000–10000 | > 10000（否决） |
| 新品占比 | 10%–25% | 5%–10% 或 > 25% | < 5% |
| 售价区间 | $15–45 | 其余 | < $10 |
| 采购占售价 | ≤ 25% | 25%–35% | > 35% |
| 广告占售价 | 8%–12% | 12%–15% | > 15% |
| 评分星级 | ≥ 4.3 | 4.0–4.3 | —（低分是差异化入口） |
| 退货率 | ≤ 5% | 5%–10% | > 10%（无差评方案则否决） |
| 变体数 | ≤ 3 | — | > 3（否决） |
| 物流占售价 | 10%–15% | 15%–20% | > 20% |
| 净利率 | > 30% | 15%–30% | < 15%（否决） |
| ABA 排名 | 10 万–20 万 | 5 万–40 万 | 其余 |
| 类目层级 | ≥ 3 级 | — | < 3 级（否决） |

## 2. 一票否决清单（命中即淘汰）

1. 大类目：只到一、二级，未下钻三、四级。
2. 品牌集中度 > 70%。
3. 类目前 10 名评价 > 10000。
4. 变体数 > 3（新卖家）。
5. 专利 / 商标风险（疑似也算）。
6. 易碎 / 抛货（单件 > 2kg 或明确易碎）。
7. 退货率 > 10% 且没有可解决的差评点。
8. 净利率 < 15%。

补充（人工判断，不进自动否决）：头部评论普遍 > 5000 且新品进不来、单一供应商、强制认证拿不出证书、平台禁售/受限类目。

## 3. 分档

| 档位 | 条件 | 动作 |
| --- | --- | --- |
| 一档 | 无否决；KPI 命中率 ≥ 80%；净利率 > 30% | 打样、开品 |
| 二档 | 无否决；命中率 ≥ 60%；净利率 ≥ 25%（小体量 > 30%） | 小批量测款 |
| 三档 | 其余 | 暂缓或换切入点 |
| 待复核 | 缺净利率，或可判定 KPI < 6 项 | 补数后重跑 |
| 淘汰 | 命中任一否决项 | 放弃 |

命中率分母 = 有数据的 KPI 项数；未知项不计入分母，但必须列进「待复核」。

## 4. 差异化清单

外在：颜色、数量、SKU 组合、包装、主图、说明书。
内在：人群（是否需审核）、使用场景、材质、外观、功能组合、防退货设计、认证前置。

## 5. 精铺闭环

细分类目 → 竞品店铺 → 相关类目 → 筛 0.5–1 年、评论不多、趋势不错、评分高、售价偏高的链接 →
核心词搜同款 → 定目标月销 → 拆差评 → 改产品/包装/主图 → 小批量测款 → 放量补货。
