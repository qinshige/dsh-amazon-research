# 利润模型与成本参数

## 1. 公式

    净利 = 售价 − 采购 − 头程 − FBA − 佣金 − 广告 − 退货 − 其它
    净利率 = 净利 ÷ 售价

红线：净利率 > 25% 才考虑；体量小（100–200 单）> 30%；物流占售价 10%–15%，> 20% 放弃；
$15–20 售价段采购价 ≤ ¥30、FBA < $4.5。

## 2. 默认参数（估算值，按实际改）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 汇率 | 7.1 CNY/USD | 按当期汇率改 |
| 佣金 | 售价 15% | 家居厨房 15%、服饰 17%、美妆/电子 8% |
| 广告 | 售价 10% | 新卖家按 12%–15% 更稳 |
| 退货损耗 | 售价 5% | 易碎/质量差调到 8%–10% |
| 头程 | ¥35/kg | 按实际物流报价；空运 10–15 天 |
| 其它 | $0.35/件 | 仓储、税费、Coupon |
| FBA | 按件重档位 | 小号标准 ≤4oz $3.22 起，大号标准 $5.30 |

## 3. 算例（售价 $29.99，采购 ¥22，件重 180g）

| 项 | 金额 |
| --- | --- |
| 售价 | $29.99 |
| 采购 ¥22 | −$3.10 |
| 头程 180g | −$0.89 |
| 佣金 15% | −$4.50 |
| FBA（大号标准） | −$3.77 |
| 广告 10% | −$3.00 |
| 退货 5% | −$1.50 |
| 其它 | −$0.35 |
| 净利 | $12.88 |
| 净利率 | 42.9% |

## 4. 敏感性（三个数）

- 采购价 +20% 后净利率还 > 20% 吗？
- 售价 −10% 后还 > 20% 吗？
- 广告 15% 时还 > 20% 吗？

三个都过 → 一档候选；任一跌破 20% → 至少二档；跌破 15% → 淘汰。

## 5. 使用规则

- 优先用 research_unit_cost 或 research_product_select 算，不手算。
- 成本参数写进报告，标「实测值」还是「经验默认值」。
- 采购价必须来自真实 1688 报价（记 URL 与日期）。
- 利润没算出来之前，不给「强烈推荐」。
