# 站外渠道、专利与合规入口

## 1. 站外选品渠道

| 类型 | 渠道 | 用途 |
| --- | --- | --- |
| 电商平台 | 沃尔玛、美客多、eBay、TikTok Shop、Temu、Etsy、独立站 | 找同款、比价格、看海外需求差异 |
| 供应链 | 1688、中国制造网、义乌购 | 找货源、比价、看起批量 |
| 社媒 | Instagram、Facebook、YouTube、TikTok | 真实场景、开箱、痛点评论 |
| 线下 | 产业带、展会、国外商超、工厂 | 工厂资源、新品、工艺 |

## 2. 专利与商标

- WIPO PATENTSCOPE：https://patentscope.wipo.int/
- Google Patents：https://patents.google.com/
- 美国商标：https://tmsearch.uspto.gov/
- 中国商标：https://sbj.cnipa.gov.cn/

要点：外观、实用新型、发明分开查；「结构差异」不是免责结论，需专业检索或律师意见。

## 3. 认证与合规

- 美国儿童品：CPC（CPSC）
- 欧盟玩具：EN71
- 电子：UL / FCC
- 食品接触/化妆品：FDA
- 平台规则：卖家后台「政策与合规」、类目审核要求

## 4. 软件

卖家精灵、Sorftime、H10、鸥鹭：只做交叉验证；软件选出的链接只代表符合特征，不代表能做。

## 5. 数据纪律

- 抓不到就写「未取到」，不补数。
- 每个结论附来源链接与抓取时间。
- 不绕过验证码、付费墙、登录限制。
