# 亚马逊选品（四途径 → 九策略 → 十维 → 差异化）

把《亚马逊选品实操指南》的四部分落成可执行动作：
**从哪找（四途径）→ 怎么筛（九策略）→ 看什么数（十维）→ 怎么定品与差异化（落地与风控）**。

本技能与 amazon-category-selection 分工：
- 本技能：**单品级**选品（候选 ASIN 的十维体检、否决、分档、差异化），以及四途径/九策略的路线规划；
- amazon-category-selection：**类目级**判断（这个细分市场值不值得进，五维 92 分制）。

两者用同一套数据纪律：数字只能来自工具/真实页面，缺了写「未取到」。

## 0. 工具与边界

| 工具 | 用途 | 消耗 |
| --- | --- | --- |
| research_product_select（action=plan） | 生成站内 7 个榜单入口、站外/软件/线下渠道、九策略适用性、十维采集清单 | 免费，不取数 |
| research_product_select（action=screen） | 候选 ASIN 十维体检：达标/警戒/不达标/未知、一票否决、一档/二档/三档/待复核/淘汰、净利率、敏感性、差异化 | 免费，不取数 |
| research_category_select | 类目大盘与五维评分（给出 nodeIdPath 后再看榜单） | MCP 9~11 次调用 / 网页 3 次 |
| research_unit_cost | 1688 采价 + 全成本净利测算 | 1688 网页查询次数 |
| research_runs | 读历史报告与产物 | 免费 |
| mcp_call | 逃生口（关键词/评论/ABA/单品详情等未封装能力） | 消耗额度 |

边界：本技能不做法律定性（专利/商标/认证只给核查入口与风险提示），不预测爆款，不编造 ASIN、售价、评论数、销量、排名。

## 1. 开工先确认 5 件事

| 要素 | 默认 | 为什么要确认 |
| --- | --- | --- |
| 站点 | US | 价格带、合规、类目结构随站点变 |
| 任务形态 | 发散找品 / 定向类目 / 验证指定 ASIN | 决定走 plan + 榜单，还是直接 screen |
| 目标价位带 | $15–45 | 低于 $10 利润被物流吃掉；高于 $80 要品牌与售后 |
| 采集上限 | 30–60 个候选 | 浏览器耗时与反爬风险随数量上升 |
| 交付物 | 采集表 CSV + 报告 MD + 结论 | 默认三件套 |

信息不全时先问，不要直接跑付费取数。

## 2. 四途径：从哪找

先调：
    research_product_select { action: "plan", marketplace: "US", category: "vases", nodeIdPath: "..." }

拿到 7 个站内入口与链接后，再按下面的纪律抓：

| 入口 | 抓什么 | 纪律 |
| --- | --- | --- |
| Best Sellers | ASIN、标题、品牌、售价、评分、评论数、BSR、卖家类型 | 一级类目只作场景，必须下钻三、四级 |
| New Releases | 上架时间、排名变化、评论数 | 不直接照抄；同款已多、价格易卷、专利 TRO 的品放弃 |
| Movers & Shakers | 24h 排名变化、当前排名 | 飙升可能是促销/站外引爆，回查趋势与专利 |
| Most Wished For | 心愿单热度、礼品属性 | 心愿单 ≠ 成交，用搜索量与竞品销量复核 |
| Gift Ideas | 适用节日、售价、评论 | 节日品生命周期短，备货与清仓要提前算 |
| Today's Deals | 折扣幅度、动销 | 可能是服务商代报，不当自然畅销证据 |
| 热搜词 / ABA | 搜索排名、搜索量、环比 | ABA 看 10–20 万区间；工具未接通就人工导出 |

站外：沃尔玛、美客多、eBay、TikTok Shop、Temu、Etsy、独立站、1688、中国制造网、义乌购；社媒看真实场景与差评。
软件：卖家精灵、Sorftime、H10、鸥鹭——只做交叉验证，不替代类目分析。
线下：产业带、展会、国外商超、工厂——积累工厂资源，常问新品。

抓不到的字段写「未取到」；不要用 web_fetch 硬凑亚马逊 JS 页面。

## 3. 九策略：怎么筛

plan 会给出每条策略的「推荐 / 可选 / 不适用」与理由。执行顺序建议：

1. **细分选品**：人群 + 类目双细分，锁定叶子节点；先跑 research_category_select。
2. **竞品店铺**：从 Top 品牌/卖家进店，看卖家类型与其他链接，循环挖相关类目。
3. **跨站点**：美国跑通后复制到 CA/AE/SA 等，核对习俗、专利、配送。
4. **关联 / 交叉 / 同场景**：围绕一个场景做组合，验证组合内每个单品的利润。
5. **高单价**：售价 $50–120、采购 ¥50–150、配送 ≤ $15–20，用高客单避开价格战。
6. **新型市场**：中东/加拿大/爱尔兰等新站点；手机电器、汽车新能源、VR/无人机/3D 打印等换代品。
7. **热门载体**：BS 榜找稳定销量、新品榜看趋势、热搜词确认载体，再围绕载体覆盖周边。

初筛只做淘汰不做推荐：命中一票否决直接放弃。

## 4. 十维：看什么数

采集表模板：assets/selection-table-template.csv（一行一个 ASIN）。
填好后调：

    research_product_select {
      action: "screen", rows: [...], marketplace: "US",
      title: "Vases 候选", profile: "beginner", targetMonthlyUnits: 100
    }

十维与阈值（与体检引擎一致，详见 references/kpi-veto.md）：

| # | 维度 | 达标 | 警戒 | 不达标 |
| --- | --- | --- | --- | --- |
| 1 | 市场容量与竞争 | Top100 月销 10–30 万；品牌集中度 < 50%；前 10 评价 < 1000 | 50%–70%；1000–10000 | > 70%；> 10000 |
| 2 | 产品趋势 | 平稳/上升；ABA 10–20 万 | 偏离区间 | 下降/衰退 |
| 3 | 价格区间 | $15–45；采购占售价 ≤ 25% | 偏离；25%–35% | < $10；> 35% |
| 4 | 评分与评价 | 评分 ≥ 4.3 | 4.0–4.3 | —（低分是差异化入口） |
| 5 | 新品占比 | 10%–25% | 5%–10% 或 > 25% | < 5% |
| 6 | 季节性 | 全年平稳 | 强季节/节日 | — |
| 7 | 质量/退货/变体 | 退货 ≤ 5%；变体 ≤ 3 | 5%–10% | > 10% 且差评不可解决；变体 > 3 |
| 8 | 运输 | 物流占售价 10%–15% | 15%–20% | > 20%；易碎/抛货 |
| 9 | 供应链 | ≥ 2 家供应商 | 单一供应商 | — |
| 10 | 侵权/认证 | 无风险；认证拿得到 | 需确认证书 | 专利/商标风险 |

## 5. 定品：分档、否决、差异化

### 5.0 先看决策单

报告开头是决策单（`profile` 决定口径）：

- **结论**：做 / 小批量测 / 先补数 / 不做；
- **致命项**：一票否决 + 画像不适配（售价、重量、变体、认证、季节、利润红线）；
- **安全边际**：采购价上限、售价下限、广告上限、退货上限；
- **首批**：变体数 × 件数、资金、目标月销、静态回本；
- **可攻击面**：评论壁垒、评分、价格带、差评点；
- **改变结论的条件**：采购价超过多少、错过窗口、拿不到证书就放弃。

`profile` 三档：`beginner`（默认，资金 <10 万、无供应链）、`operator`（10–50 万、有供应商）、`factory`（自有产线/可开模）。新手图会自动多一层教练（为什么、坑、今天/本周/下周、术语），进阶/工厂型省略。

### 5.1 分档

分档规则（与引擎一致）：
- **淘汰**：命中任一否决项。
- **待复核**：缺净利率，或可判定 KPI < 6 项。
- **一档**：无否决 + 命中率 ≥ 80% + 净利率 > 30%。
- **二档**：无否决 + 命中率 ≥ 60% + 净利率 ≥ 25%（小体量需 > 30%）。
- **三档**：其余。

一票否决：大类目（< 3 级）、品牌集中度 > 70%、前 10 评价 > 10000、变体 > 3、
专利/商标风险、易碎/抛货、退货 > 10% 且差评不可解决、净利率 < 15%。

差异化方向（引擎按证据生成，也可人工按此清单拆）：
- 外在：颜色、数量、SKU 组合、包装、主图、说明书。
- 内在：人群差异（是否需审核）、使用场景、材质、外观、功能组合、防退货设计。

判定纪律：没有证据的方向不写；「改了就能卖」不承诺，只给验证动作。

## 6. 利润、安全边际与物流

净利率 = 售价 − 采购 − 头程 − FBA − 佣金 − 广告 − 退货 − 其它。
红线：> 25% 才考虑；体量小（100–200 单）> 30%；物流占售价 10%–15%，> 20% 放弃；
$15–20 售价段采购价 ≤ ¥30、FBA < $4.5。详见 references/profit-model.md。

比“净利率点值”更有用的是**安全边际**：按目标净利率反推采购价上限、售价下限、广告上限、退货上限；再按画像首批件数算资金与静态回本。这些由决策单直接给出，不要手算。

默认参数（估算值，按实际改）：汇率 7.1、头程 ¥35/kg、佣金 15%、广告 10%、退货 5%、其它 $0.35。
采购价必须来自 1688 真实报价（记 URL 与日期）；用 research_unit_cost 采价。

物流：首批可走美森快船（30–40 天）；轻小/热销/季节性走空运（10–15 天）或快递；
补货「多补少发」，后期做包装优化；新卖家变体不超过 3 个。

## 7. 合规与风控

- 1688 图片不要直接用（工厂自述「实拍」不可信）。
- 专利：WIPO、Google Patents、商标局逐项检索；「结构差异」不是免责结论。
- 认证：CPC / EN71 / UL / FDA 等先确认证书拿得到。
- 杀猪盘：突然爆红、周期短、工厂做局推高再等专利 TRO 的品，直接放弃。
- 受限类目（危险品、液体、磁性、电池、儿童品无 CPC）先查平台规则。

1. 采集表 CSV（模板见 assets/selection-table-template.csv）
2. 选品报告 MD（research_product_select 落盘：report.md / selection.csv / manifest.json / scores.json）
